# Tessera

A mosaic tile-drafting board game for 2–4 players, built for iPhone and iPad.

**Play:** https://iand74.github.io/Tessera-/

Open the link in Safari, tap **Share → Add to Home Screen**, and it installs with its own icon, opens full screen and works offline.

- Play against computer opponents (Easy or Hard) or pass the device around
- All scoring is counted automatically, with animated end-of-round tiling
- Undo, rules screen, and your game is saved if you close the page
